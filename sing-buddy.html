How it Works

Sing Buddy is an interactive vocal training system that listens to a user's singing, identifies musical notes, and provides immediate feedback on pitch accuracy. The system combines three ESP32-based controllers, audio processing, wireless communication, and RFID user recognition to create an interactive singing experience.

When a user sings into the microphone, the listening controller processes the audio signal using a Fast Fourier Transform (FFT) to identify its dominant frequency. The detected pitch is compared against the expected musical note, triggering a green LED for a correct note or a red LED for an incorrect one.

A separate controller recognizes users through an RFID fob and communicates wirelessly using ESP-NOW. During the song challenge, the system plays a predefined sequence of notes that the user attempts to match. If a note is missed, a servo-actuated mechanism presses a button on a vibrating bracelet controller, providing tactile feedback in addition to the visual indicators.

Components

Turning a voice into a note

The listening controller uses CircuitPython and a Fast Fourier Transform (FFT) to analyze the microphone signal and estimate its dominant frequency. This frequency is mapped to a musical note and compared against the expected pitch. The detected note and LED response provide immediate feedback while also helping identify errors during testing and debugging.

Connecting the challenge mode

A separate ESP32 controller programmed in MicroPython reads an RFID fob to identify the user and sends wireless commands through ESP-NOW. During the song challenge, the system plays a sequence from "Stairway to Heaven" and evaluates the singer's pitch. When a note is missed, a servo motor physically presses a button on a vibrating bracelet controller, converting the pitch-detection result into tactile feedback.

Hardware Integration

The system combines three physical subsystems: a microphone and LED feedback unit, an RFID-based identification controller, and a servo-actuated button pusher. These components work together through embedded programming and wireless communication, allowing audio detection, user interaction, and physical feedback to operate as one system.
